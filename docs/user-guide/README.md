# HARALD — User Guide (Planned)

> HARALD does **not yet have a runnable application**. This page records the user workflows that a future manual must explain; it is **not** an instruction manual for an installed product.

## Planned guide structure

1. **Getting started:** choose local or small-library deployment, create a library, understand privacy defaults.
2. **Cataloging works:** search by title/identifier, add authors and creator roles, describe a creative work.
3. **Editions and releases:** distinguish translations, paperback/hardcover, DVD/Blu-ray, music pressings, audiobook editions, EPUB and PDF.
4. **Physical inventory:** add individually inventoried copies, barcode labels, rooms/shelves, component lists and **per-copy** physical condition; distinguish wear from lending availability and handle audited withdrawal of a single copy.
5. **Collections and lists:** use thematic groups separately from storage location.
6. **Search and discovery:** query and filter by media type, location, availability and contributors.
7. **Borrowers and circulation:** create authorized member records, loan, renew, reserve and return a **specific scanned copy**; inspect its condition upon return and block a damaged copy without affecting healthy duplicates.
8. **Multipart media:** lend/return a six-disc audiobook or box set, check missing components.
9. **Digital content:** add lawful files and configure who may open/download them.
10. **Import and export:** migrate from an old library system using preview/mapping/dry-run; preserve original identifiers, Unicode, edition relationships, **every separate physical item**, and owner-controlled data; review duplicate/conflict and loss reports.
11. **Stocktaking:** scan shelf inventory, review missing/unexpected results.
12. **Accessibility and localization:** keyboard flows, language selection and screen-reader support.
13. **Troubleshooting:** recover from invalid barcodes, import conflicts, missing assets and denied permissions.
14. **Future self-service (after staff circulation):** self-checkout at approved terminals/mobile channels, physical return intake with truthful receipt/status and a separate inspection step. A remote web click alone does not complete a return.

## Future quick-start example (not yet executable)

A user will ideally create a Work, add an Edition, register two copies with different barcodes and locations, lend only one, then observe that the second remains available. The first implementation should prove this workflow before advanced UI features.

## What is not promised yet?

Reader/playback, automated metadata enrichment, OPAC, barcode printing and custom media editors are planned for specific later milestones. The conceptual interface picture in the README is not a working screenshot.
